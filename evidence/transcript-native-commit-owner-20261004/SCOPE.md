## Existing ownership

`TranscriptPageView` owns the original committed fragment resources and their source range. Native `NodeList` owns mounting and pruning children until real message-loop/Unmount completion. Those are distinct resources: a node can already be absent from the native scene while still attached to its parent and registered by ID. Source admission must not count that pending teardown as a current row.

The page now lends its committed fragment tuple to category updates, source indexing, reader anchors, protection, page eviction and viewport resource admission. Initial composition acquires those original widgets; extension and live replacement transfer newly mounted resources only after the original source snapshot and page admission are rechecked. `ExitStack` retires rejected acquisition through native59's original synchronous prune admission and independent completion, without awaiting teardown inside the history fence. Fragment/page roots have no native ID; nested tool IDs belong to separate fragment parent registries.

End acquires the destination before replacing the source pages. Trim, page eviction and filtered projection removal commit source membership before pruning old native widgets. Existing reader compensation, width/style/body readiness, source/reader identity checks and mount awaits remain. Native completion retains Unmount, unregister, final parent layout refresh and error delivery.

`FilterState.remove` owns exact logical admission removal as well as the original projected resource retirement. A superseded projection's cleanup cannot clear a newer filter admission. Both filtered source transitions and the canonical pager use that family.
