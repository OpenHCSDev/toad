# Viewed settings: discovery and original writers

The sidebar used local-override eligibility to decide which settings existed. Files therefore exposed four UI fields and hid every other settings group. Native session advertisements were also confined to the model popup.

The dropdown now uses FormBridge's visible parameter discovery. Each field keeps its original declaration. Local fields still use the same ObjectState parent and explicit override storage. Global fields write and save the original SavedSettings object; their controls say they apply to every view and do not offer a false local override button. Hidden declarations remain hidden through FormBridge.

Native session sources supply AgentProperties. Mailbox sources supply no ACP configuration; channel and file views do not borrow the last agent's state. AgentProperties renders SessionForm over the selected session's actual advertisements and listens to its original event stream, including binding changes. The existing model popup inherits the same form, adding only popup dismissal. All edits and provider-login requests return through the original prompt and its guarded backend writer.

Applied through retained NRA plans. No manual product edits or new agent.
