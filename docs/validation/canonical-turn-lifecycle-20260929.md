# Canonical turn presentation

Arendt owns the full T4 presentation integration paired with Core S14 canonical
turn lifecycle. Consume the backend declaration-owned state and permissions;
retain generic ACP local turns and captured response-stream identity. Remove
duplicated managed lifecycle/status flags and private backend probes, with every
caller migrated. Input proof, disposition history and registry leases retain their
existing owners. No second state store or turn identity.

Shared boundaries are coordinated directly with C1 TurnSession, C3 backend/goals,
stop reason/activity, workspace status and transcript source owners. Parent owns
overall merge and installed cutover. Existing merged209 progressive compaction
receipts remain valid and separate.

Acceptance extends the existing continuous real native/ACP/Textual fixture:
fork/open/first reply, preparation and compaction, cancel and next input, A/B/A
active/inactive status, goal controls, draft and input editing. Use a localhost
provider and isolated saved state. Never replay original uncertain input.
