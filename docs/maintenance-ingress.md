# Toad maintenance ingress (draft, default OFF)

This PR adds a Toad-side client of the proposed agent-comms `MaintenanceBarrier` API. It does **not** create a second gate or enable maintenance. A never-enabled wire root remains open; an enabled non-ready, incomplete, or corrupt core witness rejects new Toad ACP spawn/reconnect and `session/prompt` stdin writes. The configured `AGENT_COMMS_ROOT` and an attached ACP wire root are both checked. A paused reconnect is declined before stopping the existing child; an unaccepted user prompt raises to the Conversation handler, which restores its text instead of treating it as dispatched.

An async ACP spawn is performed on the Toad event loop while a worker holds the core wire admission lock through process creation; the worker never awaits on the event loop. A cancelled caller settles the spawn and retires its observed child before it releases admission. This protects pause acknowledgment from a Toad spawn racing the pause. A permanently stuck OS spawn can hold admission indefinitely; this candidate makes **no bounded-retirement guarantee**. The core registry claim and native send checks are still required for children already running.

`pyproject.toml` currently pins an older agent-comms release without this API. The Toad and core artifacts must be reviewed, paired, and tested together before merge or install. If the paired API is absent, this source fails closed rather than silently bypassing a possible maintenance window. All old Toad/ACP/CLI imports can bypass new source; an externally authorized full-ingress maintenance window and verified old-process exclusion remain mandatory. No live pause/restart/install or provider call was performed.

Provider-free local pilot: set `PYTHONPATH=<isolated-core-gate-worktree>/src:<this-worktree>/src` and run `tests/maintenance_ingress_pilot.py` with the isolated Toad virtual environment. It exercises default-off fake ACP launch, spawn-vs-pause linearization, cancellation, a paused mounted wire, denied prompt/reconnect/start, and actual Toad `Agent.start` with a disposable marker-only shell. This is not full-system acceptance.
