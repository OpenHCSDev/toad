# Toad maintenance ingress (default OFF)

Merged PR67 adds a Toad-side client of the agent-comms `MaintenanceBarrier` API. It does **not** create a second gate or enable maintenance. A never-enabled wire root remains open; an enabled non-ready, incomplete, or corrupt core witness rejects new Toad ACP spawn/reconnect and `session/prompt` stdin writes. The exact child `AGENT_COMMS_ROOT` is resolved against its frozen launch `env` (including child `HOME`) and `cwd`, written back into Agent's retained launch environment at the same point that its later prompt root is bound, then passed as the canonical absolute child path. An attached ACP wire root is canonicalized at metadata binding and also checked. Parent environment changes or symlink retargeting cannot redirect these roots after admission. A paused reconnect is declined before stopping the existing child; an unaccepted user prompt raises to the Conversation handler, which restores its text instead of treating it as dispatched.

An async ACP spawn is performed on the Toad event loop while a worker holds the core wire admission lock through process creation; the worker never awaits on the event loop. A repeatedly cancelled caller cannot abandon the spawn: the worker keeps admission until the observed child is either accepted or retired. On POSIX, retirement signals the dedicated process group and checks that no live same-group member remains before releasing the lock. This does **not** prove retirement of a descendant that escaped to another group/session or of old imported processes. A permanently stuck OS spawn or unkillable member can hold admission indefinitely; this candidate makes **no bounded-retirement guarantee**. The core registry claim and native send checks are still required for children already running.

`pyproject.toml` pins merged OpenHCSDev/agent-comms `8842a6274a5326d0170aba228f48000db2dcf349`, whose full tree matches independently reviewed strict-generation core `a0a90d0`. Relative to former pin `a822a8d`, its sole production-byte change requires the legacy state generation to be an exact `int`; `true` and `1.0` can no longer compare equal to marker generation `1` and falsely open a malformed READY witness. The read-only `MaintenanceBarrier` API remains present. The uv git source pin is **not** encoded in built wheel metadata (`agent-comms[acp]` remains generic): any later deployment needs exact reviewed paired artifacts, no dependency re-resolution and installed-package origin/hash proof. Source-mode resolution can otherwise restore an old dependency. If the paired API is absent, this source fails closed rather than silently bypassing a possible maintenance window. All old Toad/ACP/CLI imports can bypass new source; an externally authorized full-ingress maintenance window and verified old-process exclusion remain mandatory. Separate merged PR68 is research-only and provides no production descendant containment. No live pause/restart/install or provider call was performed.

This is not full-system acceptance.
