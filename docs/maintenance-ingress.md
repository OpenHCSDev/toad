# Toad maintenance ingress (draft, default OFF)

This PR adds a Toad-side client of the proposed agent-comms `MaintenanceBarrier` API. It does **not** create a second gate or enable maintenance. A never-enabled wire root remains open; an enabled non-ready, incomplete, or corrupt core witness rejects new Toad ACP spawn/reconnect and `session/prompt` stdin writes. The exact child `AGENT_COMMS_ROOT` is resolved against its frozen launch `env` (including child `HOME`) and `cwd`, then written back as the canonical absolute path passed to the child. An attached ACP wire root is canonicalized at metadata binding and also checked. Parent environment changes or symlink retargeting cannot redirect these roots after admission. A paused reconnect is declined before stopping the existing child; an unaccepted user prompt raises to the Conversation handler, which restores its text instead of treating it as dispatched.

An async ACP spawn is performed on the Toad event loop while a worker holds the core wire admission lock through process creation; the worker never awaits on the event loop. A repeatedly cancelled caller cannot abandon the spawn: the worker keeps admission until the observed child is either accepted or retired. On POSIX, retirement signals the dedicated process group and checks that no live same-group member remains before releasing the lock. This does **not** prove retirement of a descendant that escaped to another group/session or of old imported processes. A permanently stuck OS spawn or unkillable member can hold admission indefinitely; this candidate makes **no bounded-retirement guarantee**. The core registry claim and native send checks are still required for children already running.

`pyproject.toml` currently pins an older agent-comms release without this API. The Toad and core artifacts must be reviewed, paired, and tested together before merge or install. If the paired API is absent, this source fails closed rather than silently bypassing a possible maintenance window. All old Toad/ACP/CLI imports can bypass new source; an externally authorized full-ingress maintenance window and verified old-process exclusion remain mandatory. No live pause/restart/install or provider call was performed.

Provider-free local pilots: set `PYTHONPATH=<isolated-core-gate-worktree>/src:<this-worktree>/src` and run `tests/maintenance_ingress_pilot.py` and `tests/maintenance_cancel_process_group_pilot.py` with the isolated Toad virtual environment. They exercise default-off fake ACP launch, spawn-vs-pause linearization, repeated cancellation and delayed retirement, exact child relative/copied/HOME root and symlink retargeting, a paused mounted wire, denied prompt/reconnect/start, actual Toad `Agent.start` with a marker-only shell, and process-group child exit. This is not full-system acceptance.
