## Current implementation under evaluation

### Unpublished Toad pointer/sidebar work

`src/toad/widgets/side_bar.py`:

- Pointer clicks no longer focus the toggle handle on mouse-down and then focus
  the sidebar title. Keyboard Tab/Enter/Space still supports entering the pane.
- `SideBarToggle.focus_on_click()` returns false. Pointer clicks invoke the
  owning `SideBar.toggle(focus=False)` directly rather than another message hop.
- Shared Channels settings still own collapse intent; the visible sidebar
  projects the updated setting immediately, and later signals are idempotent.
- Closing a pane only returns focus to the prompt when focus was inside that
  pane or keyboard activation requested it. Draft focus otherwise stays put.
- `SidebarVisibilityObserver` is a nominal panel interface. SideBar notifies
  its declared panels directly instead of scanning all descendants for concrete
  sidebar types to update spinners.
- `CommsSidebar` and `ThreadCommsSidebar` implement that interface and traverse
  their existing row collections rather than repeated CSS descendant queries.
- Managed sidebar widths come directly from the placement model instead of
  resetting width/min/max to None before applying the actual width again.
- Toggle content/tooltip updates are idempotent.
- **Remove/test the duplicate frame-request issue above before relying on the
  current published-candidate timing.**

`SessionView._use_viewport_layout()` opts the active view into viewport-local
layout, except during history-anchor transactions, which retain full layout.

### Unpublished Textual work

- `Compositor.reflow(..., visible_only=True)` optionally commits viewport
  geometry and leaves full geometry available through native lazy lookup.
- `Screen._use_viewport_layout()` defaults false; only opt-in screens use this.
  Show/Hide notifications are viewport-local in the opt-in path.
- Newly exposed widgets get resize notification when their stored dimensions
  change, even after a lazy offscreen lookup materializes full geometry.
- Arrangement cache keys include viewport size and layout update generation.
- Dirty marking uses last committed local bounds instead of querying `size`
  through an invalidated compositor and accidentally doing layout while marking
  dirty. Geometry commits dirty their new bounds.
- `_check_refresh` immediately returns when none of its refresh flags are set.
- `tests/test_viewport_layout.py` compares visible geometry and actual strips
  against a native full-layout oracle across width changes, scrolling, hidden
  geometry queries, content mutation and resize.

This is significant framework policy work; keep the parity and history checks.
Do not silently enable viewport-local lifecycle in unrelated applications.
