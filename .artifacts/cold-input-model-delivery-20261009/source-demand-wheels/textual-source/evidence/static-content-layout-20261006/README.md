colors or action metadata. Native Content width and wrapping use text and current
rules, not spans. Static now owns the native measurement contract once, shared
by its style-sensitivity and update consumers. Style independence does not itself
certify native Content measurement.

custom box/layout hooks, containers, and first unresolved visual retain layout.

force-layout without dispatching through update overrides. Native Tab Relabelled
